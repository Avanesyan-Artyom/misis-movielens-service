# Сервис рекомендаций фильмов

Команда «Netflix на минималках», БИВТ-23-АЭ-1. Проект: рекомендации фильмов на данных MovieLens ml-latest-small.

`GET /recommend/{user_id}` возвращает популярные фильмы с не менее чем пятью оценками и сглаженной средней оценкой не ниже 4. Уже оценённые пользователем фильмы исключаются. Новому пользователю показывается общая подборка. Используются данные обучающей части.

`POST /predict` возвращает прогноз оценки по модели Ridge. Отдельная логистическая регрессия оценивает вероятность оценки не ниже 4: поле `probability` содержит её оценку, `class` равен 1 при вероятности не ниже 0,5. Калибровка вероятности не проверялась. Модели используют средние оценки и число оценок пользователя и фильма. Для прогноза оценки указана метрика RMSE на проверочной выборке. Жанровый признак из предыдущего эксперимента не используется, поэтому результаты нельзя напрямую сопоставлять с его метриками NDCG.

## Структура

- `train.py` — обучение и сохранение полного Pipeline, метаданных и пяти эталонных ответов.
- `app/` — сервис FastAPI и преобразование признаков.
- `tests/` — проверка контрактов, эталонов и рекомендаций.
- `data/` — данные MovieLens и исходное описание условий использования.
- `artifacts/1.0.0/` и `artifacts/0.9.0/` — версии артефактов; модель создаётся обучением.
- `Dockerfile` — сборка контейнера, включая обучение обеих версий.

## Локальный запуск

Нужен Python 3.12. В папке проекта выполните:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python train.py --version 0.9.0
python train.py --version 1.0.0
python -m pytest -q
python -m uvicorn app.main:app --host 127.0.0.1 --port 8077
```

После запуска документация API доступна по адресу http://127.0.0.1:8077/docs. Проверка из другого окна терминала:

```bash
curl http://127.0.0.1:8077/health
curl http://127.0.0.1:8077/model-info
curl 'http://127.0.0.1:8077/recommend/1?limit=10'
curl -X POST http://127.0.0.1:8077/predict -H 'Content-Type: application/json' -d '{"user_id":1,"movie_id":1}'
curl -X POST http://127.0.0.1:8077/predict -H 'Content-Type: application/json' -d '{"user_id":0,"movie_id":1}'
```

Последний запрос возвращает 422. Неизвестный фильм или фильм без оценок в обучающей выборке возвращает 404. Неизвестному пользователю доступны общая подборка и прогноз с общим средним.

## Docker и откат

```bash
docker build -t netflix-service:1.0.0 .
docker run --rm -p 8077:8077 netflix-service:1.0.0
```

В другом терминале выполните те же `curl`-запросы, что и для локального запуска. Для отката остановите контейнер и запустите образ с предыдущим артефактом:

```bash
docker run --rm -p 8077:8077 -e MODEL_VERSION=0.9.0 netflix-service:1.0.0
curl http://127.0.0.1:8077/health
curl http://127.0.0.1:8077/model-info
```

Версия 0.9.0 подготовлена для проверки отката и отличается параметром Ridge: α=100 вместо α=10. Для возврата к версии 1.0.0 запустите контейнер без `MODEL_VERSION` либо с `MODEL_VERSION=1.0.0`.

## Данные и проверка

100 836 оценок сортируются по времени. Обучение — первые 80 668 записей, проверка — следующие 10 084, оставшиеся 10 084 отложены. Повторы удаляются до разделения; неверные данные вызывают ошибку. Средние и масштабирование рассчитываются только по обучающей части, а собственная оценка строки исключается из её признаков при обучении. `meta.json` содержит хеш файла оценок, версию и RMSE. Итоговый тест не использовался.

Данные: [GroupLens MovieLens](https://grouplens.org/datasets/movielens/latest/), F. Maxwell Harper, Joseph A. Konstan, 2015. Условия использования — в `data/MovieLens_README.txt`.
